3.1 · 조건에 맞는 행 선택

필요한 데이터만 골라내기

필요한 고객·계좌·거래를 조건으로 고르고, 원하는 순서로 조회하기.

이 장의 목표
조건 지정 → 조건 조합 → 날짜 범위 조회 → 결과 정렬

기본 문법

SELECT 컬럼명
FROM 테이블명
WHERE 조건;

WHERE절

  • 조건에 맞는 행 선택.
  • WHERE는 FROM 다음에 작성.

• 조건 없이 고객 목록 조회

SELECT customer_id, customer_name, customer_grade, branch_id
FROM customers;

• 102번 영업점 고객 조회

SELECT customer_id, customer_name, customer_grade, branch_id
FROM customers
WHERE branch_id = 102;
✓ 조건에 맞는 행만 조회하며 원본 데이터는 바뀌지 않음.
✓ 결과가 0건이어도 SQL 오류가 아닐 수 있음.
3.2 · 숫자와 문자 비교

숫자와 문자 비교

기본 문법

WHERE 컬럼명 = 값
WHERE 컬럼명 > 값
WHERE 컬럼명 <= 값
연산자의미
=같음
<>, !=, ^=같지 않음
>초과
>=이상
<미만
<=이하

• 이름이 김민준인 고객 조회

SELECT customer_id, customer_name, customer_grade, branch_id
FROM customers
WHERE customer_name = '김민준';
이름이 같아도 서로 다른 고객일 수 있음. 고객번호로 구분.

• 신용점수 600점 이하 고객 조회

SELECT customer_name, credit_score
FROM customers
WHERE credit_score <= 600;
✓ 문자값은 작은따옴표로 감싸기.
✓ 숫자는 쉼표 없이 작성. (예: 50000000)
3.3 · 범위로 조회하기

범위로 조회하기

기본 문법

WHERE 컬럼명 BETWEEN 시작값 AND 끝값

• 신용점수 700~800점 고객 조회

SELECT customer_name, credit_score
FROM customers
WHERE credit_score BETWEEN 700 AND 800;
700 이상, 800 이하를 의미함. 양 끝값도 포함.
같은 조건을 비교 연산자로 표현
WHERE credit_score >= 700
  AND credit_score <= 800
3.4 · 여러 값 중에서 고르기

여러 값 중에서 고르기

기본 문법

WHERE 컬럼명 IN (값1, 값2, 값3)

• 101·102·103번 영업점 고객 조회

SELECT customer_id, customer_name, credit_score, branch_id
FROM customers
WHERE branch_id IN (101, 102, 103);
✓ 목록 중 하나와 같으면 선택.
✓ 숫자는 그대로, 문자값은 작은따옴표로 감싸기.
3.5 · 문자 일부로 찾기

문자 일부로 찾기

기본 문법

WHERE 컬럼명 LIKE '문자 패턴'
  • %: 0개 이상의 문자.
  • _: 정확히 한 문자.

• 고객 이름이 김으로 시작하는 고객 조회

SELECT customer_name
FROM customers
WHERE customer_name LIKE '김%';

• 이름의 두 번째 글자가 ‘민’인 고객 조회

SELECT customer_name
FROM customers
WHERE customer_name LIKE '_민%';
'김%'는 김으로 시작하는 이름.
'_민%'는 두 번째 글자가 민인 이름.
3.6 · 값이 없는 데이터 확인

값이 없는 데이터 확인

기본 문법

WHERE 컬럼명 IS NULL
WHERE 컬럼명 IS NOT NULL
NULL은 값이 없거나 확인되지 않은 상태. 0이나 공백과 다름.

• 영업점코드가 등록되지 않은 고객 조회

SELECT customer_name, branch_id
FROM customers
WHERE branch_id IS NULL;
✓ 영업점코드가 NULL이라는 사실만으로 온라인 가입 고객이라고 판단할 수 없음.

• 연락처가 등록된 고객 조회

SELECT customer_name, phone_number
FROM customers
WHERE phone_number IS NOT NULL;
NULL 비교 시 주의
  • = NULL, <> NULL 대신 IS NULL, IS NOT NULL 사용.
  • Oracle에서 빈 문자열('')은 NULL로 취급하지만, 공백 한 칸(' ')은 문자값임.
3.7 · 여러 조건 함께 사용

여러 조건 함께 사용

기본 문법

WHERE 조건1 AND 조건2
WHERE 조건1 OR 조건2
  • AND: 두 조건을 모두 만족하는 행.
  • OR: 두 조건 중 하나 이상을 만족하는 행.

• 102번 영업점이면서 신용점수 800점 이상인 고객

SELECT customer_id, customer_name, branch_id, credit_score
FROM customers
WHERE branch_id = 102
  AND credit_score >= 800;

• 102번 영업점이거나 신용점수 800점 이상인 고객

SELECT customer_id, customer_name, branch_id, credit_score
FROM customers
WHERE branch_id = 102
   OR credit_score >= 800;
OR에서 두 조건을 모두 만족해도 같은 원본 행이 두 번 출력되지는 않음.
3.8 · 조건에서 제외하기

조건에서 제외하기

기본 문법

WHERE 컬럼명 NOT IN (값1, 값2)
WHERE 컬럼명 NOT BETWEEN 시작값 AND 끝값
WHERE 컬럼명 NOT LIKE '문자 패턴'

• BRONZE·NORMAL 등급을 제외한 고객 조회

SELECT customer_name, customer_grade
FROM customers
WHERE customer_grade NOT IN ('BRONZE', 'NORMAL');

• 신용점수 600~800점 범위를 벗어난 고객 조회

SELECT customer_name, credit_score
FROM customers
WHERE credit_score NOT BETWEEN 600 AND 800;
600~800점을 제외하면 600점 미만 또는 800점 초과.

• 고객 이름이 김으로 시작하지 않는 고객 조회

SELECT customer_name
FROM customers
WHERE customer_name NOT LIKE '김%';
NULL이 포함된 조건 주의
  • NOT IN 목록에 NULL을 넣으면 조회 결과가 나오지 않을 수 있음.
  • 비교 대상 컬럼이 NULL인 행도 NOT IN으로 자동 포함되지 않음.
  • NULL 행도 포함하려면 OR 컬럼명 IS NULL을 명시.
3.9 · 괄호로 조건 묶기

괄호로 조건 묶기

업무 요청
보통예금 또는 정기예금 중 잔액이 1천만원을 초과하는 계좌 조회.

기본 문법

WHERE (조건1 OR 조건2)
  AND 조건3

• 괄호 없이 작성한 조건과 결과 비교

SELECT account_number, account_type, balance
FROM accounts
WHERE account_type = '보통예금'
   OR account_type = '정기예금'
  AND balance > 10000000
ORDER BY balance, account_number;
AND가 OR보다 먼저 적용됨. 위 SQL은 보통예금을 잔액과 관계없이 포함.

• 괄호로 업무 의도를 명확하게 표현

SELECT account_number, account_type, balance
FROM accounts
WHERE (account_type = '보통예금'
       OR account_type = '정기예금')
  AND balance > 10000000
ORDER BY balance, account_number;
IN으로 간결하게 표현
WHERE account_type IN ('보통예금', '정기예금')
  AND balance > 10000000
3.10 · 원하는 순서로 정렬

원하는 순서로 정렬

기본 문법

SELECT 컬럼명
FROM 테이블명
WHERE 조건
ORDER BY 정렬컬럼 ASC 또는 DESC;
  • ASC: 오름차순. 생략하면 기본 적용.
  • DESC: 내림차순.
  • ORDER BY가 없으면 결과 행의 순서를 보장하지 않음.
  • 여러 기준은 쉼표로 구분. 앞 기준이 같은 행끼리 다음 기준 적용.

• 잔액 오름차순 정렬

SELECT account_number, account_type, balance
FROM accounts
ORDER BY balance ASC, account_number ASC;

• 생년월일 내림차순 정렬

SELECT customer_id, customer_name, customer_grade, birth_date
FROM customers
ORDER BY birth_date DESC, customer_id ASC;
생년월일 내림차순은 최근 생년월일부터, 즉 나이가 어린 고객부터 표시.

• 결과 별칭으로 정렬

SELECT account_number, balance / 10000 AS "잔액(만원)"
FROM accounts
ORDER BY "잔액(만원)" DESC, account_number ASC;
결과 별칭은 ORDER BY에서 사용 가능. 같은 SELECT문의 WHERE에서는 사용할 수 없음.

• 영업점별 신용점수 내림차순 정렬

SELECT customer_id, customer_name, branch_id, credit_score
FROM customers
ORDER BY branch_id ASC NULLS LAST,
         credit_score DESC,
         customer_id ASC;
NULL의 정렬 위치
  • Oracle 기본값: ASC는 NULLS LAST, DESC는 NULLS FIRST.
  • NULLS FIRST: NULL을 앞에, NULLS LAST: 뒤에 표시.

• 영업점 미등록 고객을 먼저 표시

SELECT customer_id, customer_name, branch_id
FROM customers
ORDER BY branch_id ASC NULLS FIRST, customer_id ASC;
DESC의 두 가지 사용 위치
  • DESC customers: 테이블 구조 확인. DESCRIBE의 줄임말.
  • ORDER BY balance DESC: 잔액 내림차순 정렬.
컬럼 위치 순번(Position)을 사용한 정렬
SELECT customer_id, customer_name, branch_id
FROM customers
ORDER BY 3, 1 DESC;
  • 컬럼 순서 변경에 영향을 받으므로 컬럼명 사용 권장.
3.11 · 날짜 범위로 조회

날짜 범위로 조회

기본 문법

WHERE 날짜컬럼 >= DATE '시작일'
  AND 날짜컬럼 < DATE '다음 기간 시작일'

• 2026년 1월 거래 조회

SELECT transaction_id, account_number, transaction_date,
       transaction_type, amount
FROM transactions
WHERE transaction_date >= DATE '2026-01-01'
  AND transaction_date < DATE '2026-02-01';
2026년 1월 1일 00:00 이상, 2월 1일 00:00 미만.
1월 31일의 시간까지 포함.
  • 날짜값은 DATE 'YYYY-MM-DD' 형식으로 작성.
  • 날짜·시간이 있는 컬럼은 시작 이상 / 다음 기간 시작 미만으로 기간 지정.
월말 날짜를 BETWEEN으로 지정하면?

끝값을 DATE '2026-01-31'로 지정하면 1월 31일 00:00까지를 의미하므로 그날 이후 시간의 거래가 빠질 수 있음.

실습 2. 2022년에 개설된 계좌의 계좌번호(account_number), 개설일자(opened_date), 잔액(balance)을 조회하는 SELECT문을 작성하세요.

실습 3. 이름의 세 번째 글자가 윤인 고객의 고객번호(customer_id), 고객명(customer_name)을 순서대로 조회하는 SELECT문을 작성하세요.

실습 6. 보통예금 또는 정기예금 중 휴면·해지 상태를 제외한 계좌의 계좌번호(account_number), 계좌종류(account_type), 계좌상태(status), 잔액(balance)을 조회하세요. 잔액 내림차순, 잔액이 같으면 계좌번호 오름차순으로 정렬하는 SELECT문을 작성하세요.

실습 7. 이름이 김·이·박으로 시작하는 고객의 고객번호(customer_id), 고객명(customer_name), 신용점수(credit_score)를 조회하세요. 신용점수 내림차순, 점수가 같으면 고객명 오름차순, 이름도 같으면 고객번호 오름차순으로 정렬하는 SELECT문을 작성하세요.

3.13 · 단원 마무리

단원 마무리

WHERE로 필요한 행을 고르고 ORDER BY로 결과 순서 지정하기.

비교 조건=, <>, !=, ^=, >, >=, <, <= 사용. 문자값은 작은따옴표로 표시.
범위와 목록BETWEEN A AND B: 양 끝값 포함. IN: 목록 중 일치하는 값 선택.
문자 패턴LIKE: %는 0개 이상의 문자, _는 문자 한 개.
NULL 확인IS NULL · IS NOT NULL 사용. = NULL로 비교하지 않음.
조건 결합AND는 모두 만족, OR는 하나 이상 만족. NOT → AND → OR 순으로 해석하며 괄호로 의도를 명확히 표현.
정렬ORDER BY 컬럼 ASC / DESC. ASC는 기본값.
날짜 범위시간을 포함한 날짜는 시작 이상 · 다음 기간 시작 미만으로 지정.
SELECT 컬럼1, 컬럼2
  FROM 테이블명
 WHERE 조건
ORDER BY 컬럼1 ASC, 컬럼2 DESC;
기억할 핵심
WHERE는 행을 선택하고 ORDER BY는 표시 순서를 지정. ORDER BY가 없으면 출력 순서를 보장하지 않음.
