고객은 몇 명인지, 잔액 합계는 얼마인지, 계좌 종류별로 어떻게 다른지 확인하기.

  • GROUP BY가 없으면 조회 대상 전체를 하나의 그룹으로 집계.
  • 집계한 결과를 조회해도 원본 데이터는 바뀌지 않음.

5.2 · 무엇을 세는지 확인하기

무엇을 세는지 확인하기

기본 문법

COUNT(*)
COUNT(컬럼명)
COUNT(DISTINCT 컬럼명)
  • COUNT(*): 조회 대상의 전체 행 수.
  • COUNT(컬럼명): 해당 컬럼이 NULL이 아닌 행 수.
  • COUNT(DISTINCT 컬럼명): NULL과 중복을 제외한 값의 개수.

• 전체 계좌 수

SELECT COUNT(*) AS "전체 계좌 수"
FROM accounts;

• 전체 고객 수와 연락처 등록 고객 수

SELECT COUNT(*) AS "전체 고객 수",
       COUNT(phone_number) AS "연락처 등록 고객 수"
FROM customers;
고객 100명 중 연락처가 등록된 고객은 90명. NULL 연락처는 COUNT(phone_number)에서 제외.

• 계좌 수와 계좌 보유 고객 수

SELECT COUNT(*) AS "계좌 수",
       COUNT(DISTINCT customer_id) AS "계좌 보유 고객 수"
FROM accounts;
계좌 수와 고객 수는 다름.
계좌는 250개, 계좌를 보유한 고객은 90명. 한 고객이 여러 계좌를 보유할 수 있음.
전체 행 개수 카운트 (NULL 포함)
COUNT(*) = COUNT(1) = COUNT(999) = COUNT('A')

같은 조회 대상에서 모두 전체 행 수를 반환. 컬럼에 NULL이 있는 행도 포함.

1, 999, 'A'는 NULL이 아닌 상수이므로 모든 행에서 개수를 셈.

5.3 · 합계·평균·최고·최저 구하기

합계·평균·최고·최저 구하기

기본 문법

SUM(숫자 컬럼)
AVG(숫자 컬럼)
MAX(컬럼명)
MIN(컬럼명)

• 최고 계좌 잔액

SELECT MAX(balance) AS "최고 잔액(원)"
FROM accounts;

• 예금 계좌의 최고·최저·총·평균 잔액

SELECT MAX(balance) AS "최고 잔액(원)",
       MIN(balance) AS "최저 잔액(원)",
       SUM(balance) AS "총 잔액(원)",
       ROUND(AVG(balance)) AS "평균 잔액(원)"
FROM accounts
WHERE account_type IN ('보통예금', '정기예금');
  • SUM: 잔액의 합계.
  • AVG: 잔액의 평균. ROUND로 평균을 정수로 반올림.
  • MAX · MIN: 가장 큰 잔액과 가장 작은 잔액.
✓ 이 예제는 보통예금·정기예금 전체를 대상으로 집계.
✓ 잔액 0원도 평균 계산에 포함.
5.4 · NULL과 0은 다르게 계산

NULL과 0은 다르게 계산

평균을 읽을 때는 어떤 값이 계산에 포함되었는지 확인.

입력값합계평균 계산평균
100, 200, NULL300300 ÷ 2150
100, 200, 0300300 ÷ 3100
  • SUM·AVG·MAX·MIN은 NULL을 제외하고 계산.
  • 0은 값이 있으므로 평균 계산에 포함.
  • NULL을 임의로 0으로 바꾸면 평균의 의미가 달라질 수 있음.
미등록 신용점수를 0점으로 바꾸는 것은 단순 표시 변경이 아님. 집계 기준을 먼저 확인.
집계 결과 해석 시 주의
  • COUNT는 셀 대상이 없으면 0을 반환.
  • SUM·AVG·MAX·MIN은 계산할 값이 없으면 NULL을 반환.
  • NULL은 실제 계산 결과인 0과 구분해야 함.
5.5 · GROUP BY · 종류별로 묶기

GROUP BY · 종류별로 묶기

기본 문법

SELECT 그룹 기준 컬럼, 집계 함수(컬럼명)
FROM 테이블명
GROUP BY 그룹 기준 컬럼
ORDER BY 정렬 기준;
원본 한 행계좌 한 개
→
GROUP BY계좌 종류
→
결과 한 행계좌 종류 한 개

• 계좌 종류별 계좌 수와 총 잔액

SELECT account_type AS "계좌 종류",
       COUNT(*) AS "계좌 수",
       SUM(balance) AS "총 잔액(원)"
FROM accounts
GROUP BY account_type
ORDER BY account_type;
  • 같은 계좌 종류끼리 묶어 계좌 수와 잔액 합계를 계산.
  • 집계하지 않고 함께 출력하는 계좌 종류는 GROUP BY에 지정.
  • GROUP BY는 정렬 기능이 아님. 결과 순서는 ORDER BY로 지정.
✓ 마이너스통장의 음수 잔액도 부호 그대로 합산.
✓ 이 예제의 총 잔액은 실습 데이터의 잔액 합계임.
5.6 · WHERE · 집계할 행 선택

WHERE · 집계할 행 선택

기본 문법

SELECT 그룹 기준 컬럼, 집계 함수(컬럼명)
FROM 테이블명
WHERE 행 조건
GROUP BY 그룹 기준 컬럼
ORDER BY 정렬 기준;
  • WHERE: 집계 대상이 될 원본 행을 선택.
  • 정상 상태 계좌를 선택하고 마이너스통장은 제외.

• 정상 상태에서 마이너스통장을 제외한 계좌 종류별 집계

SELECT account_type AS "계좌 종류",
       COUNT(*) AS "계좌 수",
       SUM(balance) AS "총 잔액(원)"
FROM accounts
WHERE status = '정상'
  AND account_type <> '마이너스통장'
GROUP BY account_type
ORDER BY account_type;
전체 계좌의 집계와 정상 계좌만의 집계는 결과가 다름. 무엇을 집계했는지 먼저 확인.
5.7 · HAVING · 집계한 그룹 선택

HAVING · 집계한 그룹 선택

기본 문법

SELECT 그룹 기준 컬럼, 집계 함수(컬럼명)
FROM 테이블명
WHERE 행 조건
GROUP BY 그룹 기준 컬럼
HAVING 집계 결과 조건
ORDER BY 정렬 기준;
구분조건의 대상예
WHERE원본 행 (Row에 대한 제한)정상 상태 계좌
HAVING집계한 그룹 (Group에 대한 제한)총 잔액이 20억원 초과

• 총 잔액이 20억원을 초과하는 계좌 종류

SELECT account_type AS "계좌 종류",
       COUNT(*) AS "계좌 수",
       SUM(balance) AS "총 잔액(원)"
FROM accounts
WHERE status = '정상'
  AND account_type <> '마이너스통장'
GROUP BY account_type
HAVING SUM(balance) > 2000000000
ORDER BY SUM(balance) DESC, account_type;
3개 계좌 종류를 집계한 후, 잔액 합계가 20억원을 초과하는 보통예금·정기예금 2개 그룹만 표시.
  • HAVING에서는 SUM(balance)처럼 집계식을 사용.
  • ORDER BY SUM(balance) DESC: 잔액 합계가 큰 그룹부터 표시.
  • 20억원은 조건 적용을 확인하기 위한 실습 기준.
SQL의 논리적 처리 흐름

FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

대상 테이블 → 행 선택 → 그룹별 집계 → 그룹 선택 → 출력 항목 구성 → 정렬

5.8 · NULL도 하나의 그룹

NULL도 하나의 그룹

• 영업점별 고객 수

SELECT branch_id AS "영업점코드",
       COUNT(*) AS "고객 수"
FROM customers
GROUP BY branch_id
ORDER BY branch_id NULLS LAST;
  • 같은 영업점코드의 고객을 모아 고객 수 집계.
  • 영업점코드가 NULL인 고객 10명도 하나의 그룹으로 표시.
  • NULL 그룹은 실제 영업점 하나를 의미하지 않음.
결과 11행 = 영업점코드 10개 + NULL 그룹 1개.
COUNT(DISTINCT branch_id)는 NULL을 제외하므로 10을 반환.
5.9 · 두 기준으로 묶기

두 기준으로 묶기

영업점 안에서 고객등급별 인원까지 나누어 확인하기.

영업점·고객등급별 고객 수

기본 문법

GROUP BY branch_id, customer_grade

• 영업점과 고객등급별 고객 수

SELECT branch_id AS "영업점코드",
       customer_grade AS "고객등급",
       COUNT(*) AS "고객 수"
FROM customers
WHERE branch_id IS NOT NULL
GROUP BY branch_id, customer_grade
ORDER BY branch_id, customer_grade;
  • 영업점코드와 고객등급의 조합이 같은 행끼리 집계.
  • 결과 한 행은 한 영업점의 한 고객등급을 의미.
  • 영업점코드가 NULL인 고객은 이 예제에서 제외.
5.10 · GROUP BY 문법과 주의사항

GROUP BY 문법과 주의사항

기본 문법

SELECT 그룹 기준 컬럼, 집계 함수(컬럼명)
FROM 테이블명
GROUP BY 그룹 기준 컬럼;

주의사항

  • SELECT 목록의 컬럼 중 그룹 함수가 없는 컬럼은 반드시 GROUP BY 절에 포함되어야함.
  • GROUP BY 절에 있는 컬럼을 반드시 SELECT 목록에 넣을 필요는 없음.

• 예시 1. 계좌 종류와 잔액 합계를 함께 표시

SELECT account_type AS "계좌 종류",
       SUM(balance) AS "총 잔액(원)"
FROM accounts
GROUP BY account_type
ORDER BY account_type;

• 예시 2. 계좌 종류로 묶되 잔액 합계만 표시

SELECT SUM(balance) AS "총 잔액(원)"
FROM accounts
GROUP BY account_type
ORDER BY account_type;
그룹 기준도 함께 출력하는 방식 권장.
문법적으로 생략할 수 있지만, 어떤 계좌 종류의 합계인지 확인하려면 예시 1처럼 함께 표시.

5.13 · 단원 마무리

단원 마무리

여러 행을 집계하고 그룹별 결과에 조건 적용하기.

개수COUNT(*): 전체 행 수 · COUNT(컬럼): NULL 제외 · COUNT(DISTINCT 컬럼): NULL과 중복 제외.
합계·평균·최고·최저SUM · AVG · MAX · MIN은 NULL을 제외하고 계산. 0은 값으로 포함.
GROUP BY같은 기준값끼리 묶어 집계. 집계하지 않고 그대로 출력하는 컬럼은 GROUP BY에 포함.
WHERE · HAVINGWHERE는 원본 행에 대한 조건, HAVING은 집계한 그룹에 대한 조건.
빈 집계 결과계산할 값이 없으면 COUNT는 0, SUM·AVG·MAX·MIN은 NULL 반환.
논리적 흐름FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
SELECT 그룹컬럼, SUM(숫자컬럼)
  FROM 테이블명
 WHERE 행 조건
GROUP BY 그룹컬럼
HAVING SUM(숫자컬럼) > 기준값
ORDER BY SUM(숫자컬럼) DESC;
기억할 핵심
계좌 수와 고객 수는 다름. 무엇을 세는지, 결과 한 행이 무엇을 의미하는지 확인.
