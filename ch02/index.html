실습용 테이블 ERD

ERD란?

ERD(Entity Relationship Diagram, 개체-관계 다이어그램)는 데이터의 구조와 관계를 시각적으로 표현한 데이터 설계도임.

건축 전에 건물 설계도를 그리듯, 소프트웨어 개발 전에 데이터 구조를 미리 파악하고 정리하는 데 활용함.

2.3 · 첫 조회: SELECT와 FROM

첫 SELECT문 실행하기

기본 문법

SELECT 컬럼명
FROM 테이블명;
영업점 정보를 확인하려면?

• 영업점의 모든 컬럼 조회

실행 SQL
SELECT *
FROM branches;
SQL 작성의 기본 약속
  • SELECT·FROM 등 키워드는 대문자로 통일 권장.
  • 컬럼은 쉼표로 구분.
  • SQL 문장 끝 표시 세미콜론(;).
  • 키워드와 일반적인 테이블·컬럼 이름은 대소문자를 구분하지 않음.
  • 문자값과 큰따옴표로 감싼 이름은 대소문자에 주의.
  • 한 문장을 여러 줄로 작성할 수 있으나 SELECT 같은 단어 중간을 나누지는 않음.

대출번호와 대출금리를 조회.

• 대출번호·금리

실행 SQL

2.5 · 결과 제목 바꾸기

결과 제목을 업무 용어로 바꾸기

열 별칭 (Column alias)

  • 조회 결과의 컬럼 제목. (원본 테이블의 컬럼명은 바뀌지 않음)
  • 기본 작성 방식 : 컬럼명 AS 별칭
  • AS 생략 가능
  • 공백·특수문자를 포함하거나 대소문자를 구분할 경우 반드시 큰따옴표 사용

• 고객명과 고객등급에 별칭 지정

실행 SQL
SELECT customer_name  AS "고객명",
       customer_grade AS "고객등급"
FROM customers;
2.6 · 숫자 계산과 단위 변환

저장된 값으로 계산해 보기

계산한 값을 조회해도 원본 데이터는 바뀌지 않음.

• 잔액을 원·만원 단위로 함께 조회

실행 SQL
SELECT account_number AS "계좌번호",
       balance AS "잔액(원)",
       balance / 10000 AS "잔액(만원)"
FROM accounts;
✓ 숫자는 10000처럼 쉼표 없이 작성.
✓ 금액의 단위를 결과 제목에 함께 표시.
계산 순서 비교

곱셈·나눗셈을 덧셈·뺄셈보다 먼저 계산. 괄호로 순서를 명확히 표현.

• 두 계산식의 차이 확인

실행 SQL
SELECT account_number,
       balance + 10000 / 10000 AS "계산A",
       (balance + 10000) / 10000 AS "계산B(만원)"
FROM accounts;
선택 실습 · 금리 0.5%p 상승 가정

• 저장된 금리와 가정 금리 비교

실행 SQL
SELECT loan_id,
       interest_rate AS "현재금리(%)",
       interest_rate + 0.5 AS "0.5%p 상승 가정 금리(%)"
FROM loans;
NULL의 의미

0이나 공백(' ')이 아닌, 값이 없거나 아직 확인되지 않은 상태(Unknown)를 의미함.

NULL이 포함된 모든 산술 계산(+, −, *, / 등)의 결과는 항상 NULL이 됨.

예: NULL + 10 = NULL

2.7 · 문자 표시와 연결

문자를 표시하고 이어 붙이기

직접 표시할 문자는 작은따옴표, 결과 제목은 큰따옴표로 작성.

• 고정된 문자를 결과에 표시

실행 SQL
SELECT customer_name AS "고객명",
       '고객' AS "구분"
FROM customers;

• 이름과 등급 사이에 쉼표·공백 넣기

실행 SQL
SELECT customer_name || ', ' || customer_grade AS "고객 정보"
FROM customers;
기호역할예
' '직접 표시할 문자'고객', ', '
" "결과 컬럼의 제목AS "고객 정보"
||문자 이어 붙이기customer_name || ', ' || customer_grade
직접 해보기 · 구분 문자를 쉼표에서 / 로 바꾸어 결과 비교.
2.8 · 중복 없이 조회하기

종류를 중복 없이 확인하기

DISTINCT

  • 조회 결과에서 중복을 제외함. (원본 행을 삭제하지 않음)

• 계좌종류 조회

실행 SQL
SELECT account_type
FROM accounts;

• 계좌종류를 중복 없이 조회

실행 SQL
SELECT DISTINCT account_type
FROM accounts;
계좌 250건에서 계좌종류 4개를 확인.
DISTINCT는 정렬을 보장하지 않음.
고객번호로 확장하기

한 고객이 여러 계좌를 보유할 수 있으므로 계좌 테이블의 고객번호는 반복 가능.

• 계좌를 보유한 고객번호 목록

실행 SQL
SELECT DISTINCT customer_id
FROM accounts;
여러 컬럼을 함께 선택하면?

DISTINCT는 선택한 컬럼값의 조합 전체로 중복을 판단.

• 고객번호·계좌종류 조합

실행 SQL
SELECT DISTINCT customer_id, account_type
FROM accounts;

고객번호만 같아도 계좌종류가 다르면 서로 다른 결과 행.

오류 해결 퀴즈

다음 3개 SQL문의 오류를 찾아 수정한 뒤 결과를 확인하세요.

1. 쉼표 확인

오류 찾기용 SQL

2. 곱셈 기호 확인

오류 찾기용 SQL
SELECT balance x 2
FROM accounts;

3. 공백이 있는 별칭 확인

오류 찾기용 SQL
SELECT branch_name AS Branch Name

4. 종합 오류 찾기

다음 SELECT문에는 4가지 코딩 오류(구문 및 식별자 오류)가 있습니다. 오류 원인 4가지를 찾아 바르게 수정하여 실행하세요.

SELECT customer_no, account_type balance x 12 ANNUAL BALANCE
FROM accounts;

2.12 · 단원 마무리

단원 마무리

SELECT로 필요한 컬럼을 선택하고 결과를 읽기 좋게 표현하기.

구조 확인DESC 테이블명: 컬럼명과 데이터 타입 확인.
SELECT · FROMSELECT는 출력 항목, FROM은 조회할 테이블 지정.
열 별칭컬럼명 AS 별칭. 공백·특수문자 또는 대소문자 구분 시 큰따옴표 사용.
산술 계산+, -, *, / 사용. 숫자는 쉼표 없이 작성.
문자 표시와 연결문자값은 작은따옴표로 감싸고 ||로 연결.
DISTINCT조회 결과의 선택한 컬럼 조합에서 중복 제외.
SELECT DISTINCT 컬럼1, 컬럼2 AS 별칭
  FROM 테이블명;
기억할 핵심
조회 결과의 별칭·계산·중복 제외는 원본 데이터를 변경하지 않음.
