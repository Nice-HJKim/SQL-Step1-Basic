4.1 · 함수로 결과 다듬기

데이터를 더 편하게 다루기

문자 일부를 꺼내고, 금액을 계산하고, 날짜와 빈 값을 읽기 좋게 표시하기.

이 장의 목표
문자 추출 → 반올림·버림 → 날짜 계산 → 표시 형식·NULL 처리

기본 문법

함수명(입력값)
입력값김민준
→
처리첫 글자 추출
→
결과값김

함수

  • 입력값을 받아 계산·가공한 결과값을 반환.
  • 단일행 함수: 각 행의 값을 처리하여 행마다 결과값을 반환.
  • 다중행 함수: 여러 행의 값을 처리하여 그룹마다 하나의 결과값을 반환.
4.2 · 문자 일부와 글자 수

문자 일부와 글자 수

기본 문법

SUBSTR(문자값, 시작 위치, 가져올 글자 수)
LENGTH(문자값)
  • SUBSTR: 지정한 위치에서 문자 일부 추출.
  • LENGTH: 문자의 글자 수 반환.

• 고객 이름의 첫 글자 추출

SELECT customer_id, customer_name,
       SUBSTR(customer_name, 1, 1) AS "첫 글자"
FROM customers
ORDER BY customer_id;

• 고객 이름의 글자 수 확인

SELECT customer_id, customer_name,
       LENGTH(customer_name) AS "이름 길이"
FROM customers
ORDER BY customer_id;
끝에서부터 추출하기
SUBSTR(문자값, -6)

음수 시작 위치는 문자열 끝에서 계산. -6은 뒤에서 여섯 번째 위치이며, 길이를 생략하면 끝까지 추출.

글자 수와 저장 크기

LENGTH는 글자 수를 확인하는 함수. 저장에 사용하는 바이트 수와는 다름. 현재 실습 고객명은 모두 세 글자로 구성됨.

4.3 · 숫자 반올림과 버림

숫자 반올림과 버림

기본 문법

ROUND(숫자, 남길 소수 자리수)
TRUNC(숫자, 남길 소수 자리수)
  • ROUND: 지정한 자리까지 남기도록 반올림.
  • TRUNC: 지정한 자리 아래의 숫자를 잘라냄.
  • 자리수 2는 소수 둘째 자리까지, 1은 소수 첫째 자리까지, 0은 정수로 표시.
DUAL 테이블이란?
  • 연산 결과나 함수 값을 확인할 수 있도록 Oracle이 제공하는 1행 1열 시스템 테이블.
  • 업무 테이블을 조회하지 않고도 FROM DUAL을 사용해 계산 결과를 한 행으로 확인 가능.

• 같은 숫자로 반올림과 버림 비교

SELECT 45.926 AS "원래 값",
       ROUND(45.926, 2) AS "반올림 결과",
       TRUNC(45.926, 2) AS "버림 결과"
FROM dual;

• 대출원금을 억원 단위로 반올림·버림

SELECT loan_id, loan_amount,
       loan_amount / 100000000 AS "대출원금(억원)",
       ROUND(loan_amount / 100000000, 1) AS "반올림(억원)",
       TRUNC(loan_amount / 100000000, 1) AS "버림(억원)"
FROM loans
ORDER BY loan_id;
함수 안의 계산 순서

ROUND(loan_amount / 100000000, 1)은 대출원금을 억원 단위로 바꾼 값을 반올림하는 식.

4.4 · 현재 날짜와 기준일

현재 날짜와 기준일

기본 문법

SELECT SYSDATE
FROM dual;

• DB 기준 현재 날짜와 시간 확인

SELECT SYSDATE AS "현재일시"
FROM dual;
  • SYSDATE: DB 서버 기준 현재 날짜와 시간 반환.
  • 화면에 날짜만 보여도 값에는 시간 정보가 포함됨.
  • 실행 시점에 따라 결과가 달라짐.
  • 클라우드 실습 환경의 서버 시간은 한국 시간과 다를 수 있음.
이 장의 날짜 계산 기준
날짜 계산 예제는 2026-03-31로 고정.
SYSDATE 예제만 실행 시점의 날짜와 시간을 표시.
날짜를 직접 지정하기
DATE '2026-03-31'

지정한 날짜의 00:00을 의미함. 두 DATE 값을 뺀 결과는 일 단위이며 시간 차이가 있으면 소수도 포함됨.

4.5 · 개설 후 경과 개월 수

개설 후 경과 개월 수

기본 문법

MONTHS_BETWEEN(기준일, 개설일)
  • 첫 번째 날짜가 더 늦으면 양수, 더 이르면 음수 반환.
  • 결과에 소수가 나올 수 있으므로 ROUND로 표시 자릿수 조정.

• 기준일 현재 개설 후 경과 개월 수

SELECT account_number, opened_date,
       ROUND(MONTHS_BETWEEN(DATE '2026-03-31', opened_date), 2)
           AS "개설 후 경과 개월 수"
FROM accounts
ORDER BY opened_date, account_number;
✓ 날짜 간 계산값을 소수 둘째 자리까지 반올림한 결과.
✓ 이 예제는 해지 계좌도 포함하며 개설일 이후의 경과 기간을 계산.
개월 수를 해석할 때

MONTHS_BETWEEN은 Oracle의 날짜 계산 규칙을 따름. 같은 일자이거나 두 날짜가 모두 월말이면 정수, 그 외 소수 부분은 일반적으로 31일 기준으로 계산됨.

반올림한 값을 정확히 완료된 개월 수나 계약상 유지 기간으로 해석하지 않음.

4.6 · 개월 더하기와 월말

개월 더하기와 월말

기본 문법

ADD_MONTHS(날짜, 더할 개월 수)
LAST_DAY(날짜)
  • ADD_MONTHS: 날짜에 지정한 개월 수를 더함.
  • LAST_DAY: 해당 날짜가 속한 달의 마지막 날짜 반환.

• 개설일의 12개월 후 날짜 계산

SELECT account_number, opened_date,
       ADD_MONTHS(opened_date, 12) AS "12개월 후 날짜"
FROM accounts
ORDER BY account_number;
계산상 12개월 후 날짜이며, 상품 계약에 따른 실제 만기일을 뜻하지 않음.

• 개설월의 마지막 날짜 확인

SELECT account_number, opened_date,
       LAST_DAY(opened_date) AS "개설월 말일"
FROM accounts
ORDER BY account_number;
월말 날짜 계산 시 주의

ADD_MONTHS는 입력 날짜가 월말이거나 대상 월에 같은 일자가 없으면 대상 월의 말일로 보정함.

예: ADD_MONTHS(DATE '2026-01-31', 1) → 2026-02-28.

4.7 · 날짜를 읽기 좋게 표시

날짜를 읽기 좋게 표시

기본 문법

TO_CHAR(날짜, '원하는 날짜 포맷')

날짜 포맷

  • YYYY: 네 자리 연도.
  • MM: 두 자리 월.
  • DD: 두 자리 일.
  • DY: 요일 약칭. 예: 목.
  • DAY: 요일 전체 이름. 예: 목요일.
  • HH24: 24시간 기준 시각(00~23).
  • MI: 두 자리 분.
  • SS: 두 자리 초.
✓ MM은 월, MI는 분을 의미함.
✓ 날짜와 시간 표시 예: YYYY-MM-DD HH24:MI:SS
요일 표시와 언어 설정

DY와 DAY의 요일 표시는 날짜 언어 설정에 따라 달라짐. 한국어 요일을 지정하려면 세 번째 인수 사용.

TO_CHAR(opened_date, 'DY', 'NLS_DATE_LANGUAGE=KOREAN')
TO_CHAR(opened_date, 'fmDAY', 'NLS_DATE_LANGUAGE=KOREAN')

fmDAY는 요일 이름 뒤의 채움 공백을 제거함.

• 날짜를 연월일 형식으로 표시

SELECT account_number,
       TO_CHAR(opened_date, 'YYYY-MM-DD') AS "개설일자"
FROM accounts
ORDER BY account_number;
✓ TO_CHAR 결과는 날짜가 아닌 문자.
날짜 조건은 이전 장처럼 작성
WHERE opened_date >= DATE '2022-01-01'
  AND opened_date < DATE '2023-01-01'

표시 형식과 조회 조건을 구분. 연도 조회는 날짜 범위로 표현 가능.

4.8 · 연도를 정확하게 입력

연도를 정확하게 입력

생년월일·계약일의 연도는 네 자리로 명확하게 입력.

1988년은 88 대신 1988로 작성.
두 자리 연도는 해석 방식에 따라 다른 세기의 날짜가 될 수 있음.
  • TO_CHAR: 날짜를 원하는 형식의 문자로 표시.
  • TO_DATE: 문자를 지정한 형식으로 해석하여 날짜로 변환.

네 자리 연도로 날짜 지정

TO_DATE('1988/08/18', 'YYYY/MM/DD')

1988년 8월 18일을 의미함.

보충: 두 자리 연도의 해석 · YY·RR·YYYY·RRRR

기본 문법

TO_DATE(문자, '입력 날짜 포맷')
TO_CHAR(날짜, '출력 날짜 포맷')
  • TO_DATE: 문자를 지정한 형식으로 해석하여 날짜로 변환.
  • TO_CHAR: 날짜를 지정한 형식의 문자로 표시.
형식TO_CHAR · 날짜 출력TO_DATE · 문자 해석
YY연도 끝 두 자리현재 세기를 적용
RR연도 끝 두 자리현재 연도와 입력 연도로 세기 판단
YYYY네 자리 연도입력한 연도를 사용
RRRR네 자리 연도네 자리 입력은 그대로 사용
두 자리 입력은 RR 규칙 적용

• 같은 생년월일 문자를 네 가지 형식으로 해석

SELECT
    TO_CHAR(TO_DATE('88/08/18', 'YY/MM/DD'),
            'YYYY-MM-DD') AS "YY 해석",
    TO_CHAR(TO_DATE('88/08/18', 'RR/MM/DD'),
            'YYYY-MM-DD') AS "RR 해석",
    TO_CHAR(TO_DATE('88/08/18', 'YYYY/MM/DD'),
            'YYYY-MM-DD') AS "YYYY 해석",
    TO_CHAR(TO_DATE('88/08/18', 'RRRR/MM/DD'),
            'YYYY-MM-DD') AS "RRRR 해석"
FROM dual;
  • 현재 연도 2026년 기준: YY는 2088년, RR은 1988년으로 해석.
  • YYYY는 0088년, RRRR은 RR 규칙에 따라 1988년으로 해석.
  • 안쪽 TO_DATE로 날짜 변환 후, 바깥 TO_CHAR로 연도를 네 자리로 표시.
✓ 생년월일·과거 계약일은 세기까지 정확하게 확인.
✓ 연도를 네 자리로 입력하고 YYYY 사용 권장.
✓ RR이 항상 1900년대로 변환하는 것은 아님.
보충 · RR의 세기 판단 기준
현재 연도 끝 두 자리입력 00~49입력 50~99
00~49현재 세기이전 세기
50~99다음 세기현재 세기

RRRR에 두 자리 연도를 입력한 경우에도 동일하게 적용.

4.9 · NULL을 안내 문구로 표시

NULL을 안내 문구로 표시

기본 문법

NVL(확인할 값, NULL일 때 표시할 값)
  • 값이 있으면 원래 값 반환.
  • NULL이면 지정한 대체값 반환.
  • 확인할 값과 NULL일 때 표시할 값의 자료형을 맞춰 사용.

• 미등록 연락처를 안내 문구로 표시

SELECT customer_id, customer_name,
       NVL(phone_number, '미등록') AS "연락처"
FROM customers
ORDER BY customer_id;
✓ 연락처가 NULL인 고객만 미등록으로 표시.
4.10 · 선택 보충

선택 보충

필요할 때 찾아 쓰는 문자 정리와 날짜 처리.

영문 소문자 변환 · LOWER

기본 문법

LOWER(문자값)

• 영문을 소문자로 바꾸기

SELECT 'User1001@Example.COM' AS "변환 전",
       LOWER('User1001@Example.COM') AS "변환 후"
FROM dual;
영문의 대소문자를 통일하는 기능. 한글에는 대소문자 구분이 없으며, 이메일 유효성을 검사하는 기능은 아님.
양끝 공백과 특정 문자 제거 · TRIM / REPLACE

기본 문법

TRIM(문자값)
REPLACE(문자값, '찾을 문자', '바꿀 문자')

• 양끝 공백 제거와 하이픈 제거 비교

SELECT TRIM('  iM뱅크  ') AS "양끝 공백 제거",
       REPLACE('506-12-000001', '-', '') AS "하이픈 제거"
FROM dual;
  • TRIM: 기본적으로 양끝 공백 제거. 중간 공백은 그대로 유지.
  • REPLACE: 문자열에서 일치하는 부분을 찾아 치환.
  • REPLACE의 바꿀 문자를 빈 문자열로 지정하면 해당 부분 제거.
개설월의 첫날 · 날짜 TRUNC

기본 문법

TRUNC(날짜, 'MM')

• 개설월의 첫날 구하기

SELECT account_number, opened_date,
       TRUNC(opened_date, 'MM') AS "개설월 첫날"
FROM accounts
ORDER BY account_number;
해당 월의 1일 00:00을 반환. 숫자 TRUNC와 달리 날짜의 월 아래 단위를 잘라내는 용도.

4.12 · 단원 마무리

단원 마무리

문자·숫자·날짜를 가공하고 NULL을 적절하게 표시하기.

문자SUBSTR: 일부 추출 · LENGTH: 글자 수.
숫자ROUND: 반올림 · TRUNC: 지정 자리 아래 숫자 버림.
현재 날짜SYSDATE: DB 서버 기준 현재 날짜와 시간.
날짜 계산MONTHS_BETWEEN: 개월 차이 · ADD_MONTHS: 개월 더하기 · LAST_DAY: 월말.
날짜 변환TO_CHAR: 날짜 → 문자 · TO_DATE: 문자 → 날짜. 연도는 네 자리로 명확하게 입력.
날짜 포맷YYYY: 연도 · MM: 월 · DD: 일 · DY/DAY: 요일 · HH24: 시 · MI: 분 · SS: 초.
NULL 대체NVL(값, 대체값): NULL이면 대체값 반환. 자료형을 맞춰 사용.
기억할 핵심
MM은 월, MI는 분. 날짜 계산 결과와 실제 상품의 만기·계약 기준은 구분.
